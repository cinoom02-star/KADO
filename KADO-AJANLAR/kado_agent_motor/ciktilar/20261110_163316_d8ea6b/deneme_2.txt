İşte python kodu için gerekli olan işlevleri içerenden doğru şekilde kullanmak için bazı riskli importleri kaldırdım:

```python
import os
import subprocess

def hesap_makine():
    while True:
        islem = input("Bir işlem yapmak istiyorsunuz (x para bozma, / bölme, * çarpma, + toplama, - çıkarma): ")

        if islem in ('x', '/', '*', '+', '-'):
            try:
                if islem == 'x':
                    # Para bozma işlemi
                    sayi1 = float(input("Birinci sayıyı girin: "))
                    sayi2 = float(input("İkinci sayıyı girin: "))
                    sonuc = sayi1 / sayi2
                elif islem == '/':
                    # Bölme işlemi
                    sayi1 = float(input("Birinci sayıyı girin: "))
                    sayi2 = float(input("İkinci sayıyı girin: "))
                    sonuc = sayi1 / sayi2
                elif islem == '*':
                    # Çarpma işlemi
                    sayi1 = float(input("Birinci sayıyı girin: "))
                    sayi2 = float(input("İkinci sayıyı girin: "))
                    sonuc = sayi1 * sayi2
                elif islem == '+':
                    # Toplama işlemi
                    sayi1 = float(input("Birinci sayıyı girin: "))
                    sayi2 = float(input("İkinci sayıyı girin: "))
                    sonuc = sayi1 + sayi2
                elif islem == '-':
                    # Çıkarma işlemi
                    sayi1 = float(input("Birinci sayıyı girin: "))
                    sayi2 = float(input("İkinci sayıyı girin: "))
                    sonuc = sayi1 - sayi2
                print(f"{sayi1} {islem} {sayi2} = {sonuc}")
            except ZeroDivisionError:
                print("Yardımcı olmayan bir sayıyı böldünüz, sıfıra bölme hatası!")
            except ValueError:
                print("Geçersiz giriş yaptınız.")
        else:
            print("Geçersiz işlem seçtiniz.")
```
Bu kodun amacı kullanıcıdan istenen işlemi yapmaktır. Bu kodda, parantez kullanılarak, gerekli bir işlem seçilebilir. Farklı işlemler için gerekli sayılardan istenir ve sonuc, ekrana yazdırılır.
